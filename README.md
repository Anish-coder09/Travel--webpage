# 🌍 Around Web - Travel Website

A modern and responsive travel website built using HTML, CSS, and JavaScript. This project showcases beautiful travel destinations, interactive UI sections, and a clean user experience for travelers exploring new places.

## 🔗 Live Demo

🌐 Visit Website:
[Around Web Travel Website](https://6a0d6a0455cdaf0e525ea6c0--aroundweb.netlify.app/?utm_source=chatgpt.com)

---

## ✨ Features

* Responsive travel website design
* Beautiful landing page with travel destinations
* Smooth navigation and interactive UI
* Modern layout using HTML, CSS, and JavaScript
* Mobile-friendly interface
* Attractive animations and styling

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Responsive Web Design

---

## 🚀 Getting Started

### Clone the Repository

### Open Project
